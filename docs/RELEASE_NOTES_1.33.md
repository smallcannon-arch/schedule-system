# 排課輔助系統 1.33

## 資料建置引導

- 資料建置頁改為四個明確步驟：班級資料、教師資料、科目節數、配課資料。
- 每個步驟會顯示用途、目前筆數與「完成／待完成」狀態，點擊步驟即可直接切換編輯區。
- 下方頁籤同步標示步驟編號，讓承辦人依序完成資料，不必猜測操作順序。

## 教師登入名冊

- 建立或載入案件後，「下載教師帳號 CSV 範本」會改為「下載依配課預填的教師名冊」。
- 系統依「教師與配課」自動帶入教師姓名、登入角色、導師班級、任教班級與任教科目。
- 承辦人只需補上學校 Google 帳號，再將 CSV 匯回系統，不必逐位重選角色或負責班級。
- 匯入後只把 Google 帳號合併回目前案件；角色、導師班級與配課仍以案件資料為準，避免 CSV 誤改排課設定。
- 完整名冊會自動同步為教師登入權限；部分名冊匯入採追加方式，不會先刪除既有登入帳號。
- 教支人員若不需登入，可保留空白帳號；系統匯入時會略過該列。
- 尚未建立案件時仍保留通用 CSV 範本，供學校先行建立教師登入名冊。

## 安全與相容性

- 下載檔保留 CSV 公式注入防護。
- 後端仍會檢查 Google 帳號格式、學校 Workspace 網域、重複帳號與導師班級。
- 既有 Excel 母版與「教師與配課」頁面不需更改，原有直接填寫帳號後同步的方式仍可使用。
