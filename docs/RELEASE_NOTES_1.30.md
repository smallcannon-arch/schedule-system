# 排課輔助系統 1.30

## 語言分組安排

- 前台新增「同年級一起上」與「各語別分開上」兩種安排方式。
- 「同年級一起上」沿用共同時段，原班課表鎖定一節本土語文。
- 「各語別分開上」可為每個語別分別設定時段、來源班級、教師與教室，不再要求同年級使用相同時段。
- 「各語別分開上」可指定原班可抽離科目；CP-SAT 會把原班同節綁定在勾選科目內。
- 同班不同學生可在同一時段參加不同語別；各組仍分別檢查教師與教室衝突。
- Excel 母版新增「安排方式」欄。多時段資料必須明確選擇「各語別分開上」，系統不會依資料形狀自動切換。

## 課表與節數

- 各語別分開上時，分組教師節數按群組各計一次，不因來源班級數重複累加。
- 原班課表保留原課程，並在同一格標示「抽離：語別」，避免整班課程被分組資料覆蓋。
- 該年級若仍設定「本土語文」節數，原班課程照常排且必須完成配課；節數為 0 或未建立時，才由語言抽離群組承接。
- 分組的教師、協同教師與教室仍套用硬規則衝堂檢查。
- 班級、教師課表與正式發布檢核皆支援新的分開上模式。
- 人力資源網與校務系統若出現同班同節多筆語言抽離資料，會先阻擋上傳檔並提示改用課表匯出，待外部格式確認後再開放。

## 相容性

- 既有案件預設維持「同年級一起上」，不會自動改變原本鎖課結果。
- 舊母版沒有「安排方式」時仍按「同年級一起上」處理；若同年級填了多個時段，匯入會要求補選模式，不會改變既有案件行為。
