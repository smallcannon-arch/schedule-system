# 排課輔助系統 1.34

## 依授課教師安排專科教室

- 步驟 3 的教室改為科目預設值，既有案件與既有排課方式維持不變。
- 步驟 4 會依配課自動彙整「科目、授課教師、任教班級」，不必逐班重複設定。
- 同一科目需要依授課教師使用不同教室時，只需修改例外教師；其他教師繼續沿用科目預設教室。
- 教室採「班級例外、教師例外、科目預設」的明確優先順序，保留既有單班特殊安排。

## 一致性與安全

- CP-SAT 排課、正式發布複驗、教師個人課表及導師調整工作區使用同一套教室判定。
- 教師或科目更名時會同步更新教室設定；刪除時會一併清除對應資料。
- 後端會攔截不存在的教師、科目或教室，避免過期設定靜默套用。
- 既有雲端案件未包含教師教室設定時，仍完全沿用原有科目與班級教室設定。
