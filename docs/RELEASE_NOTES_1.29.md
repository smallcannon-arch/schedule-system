# 排課輔助系統 1.29

## 固定課程

- 左側「排課條件」新增固定課程入口，可直接選班級、科目並點選星期節次。
- 執行排課頁新增固定課程捷徑，不再需要到 Excel 母版尋找設定。
- 排課前會檢查同班同時段重複、教師衝堂、超過科目週節數及年級不上課時段。
- 語言分組與資源班仍由各自頁面管理，避免相同課程在多個入口重複修改。

## 語言分組共同課程

- 一個年級可只選實際參與的來源班級，不再強制鎖定全年級所有班級。
- 同一共同時段可建立多個平行上課群組，例如三個原班合併拆成兩個閩南語群組。
- 平行群組預設沿用共同課程的來源班級，少數學生另行分組時才需展開調整。
- 原班課表同一節只鎖定一次；教師授課節數則依平行群組分別計算。

## 匯出與相容性

- 班級課表同一時段只顯示一筆「本土語文（分組上課）」，避免兩個群組重複佔格。
- 教師課表仍依各群組與授課教師分別顯示。
- 舊案件未記錄來源班級時，會沿用該年級全部班級，避免載入後遺失既有鎖課。
